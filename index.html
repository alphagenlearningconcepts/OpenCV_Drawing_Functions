Core Foundation

Introduction to NumPy

What Does NumPy Do?

Python's Fast Number Grid Library
  • Computers see pictures as grids of pixel numbers (Height, Width, 3 Channels).
  • NumPy lets Python create blank canvases and color thousands of pixels instantly.
  • When you install OpenCV, NumPy is installed by default—no extra setup needed.
STANDARD IMPORTS Ready to use!
import cv2
import numpy as np
Remember OpenCV's 3 Color Channels (BGR):
1: B (Blue)
0 – 255
2: G (Green)
0 – 255
3: R (Red)
0 – 255
Notice: OpenCV uses BGR instead of RGB!
